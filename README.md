# Sistema de Controle e Gestão de Resíduos Hospitalares

Projeto académico desenvolvido para a gestão e registo do fluxo de resíduos em ambiente hospitalar, permitindo o controlo de quantidades e pesos por categorias, geração de relatórios em Excel, extração de dados de PDFs e visualização gráfica.

## Tecnologias Utilizadas
- **Backend:** Python com Flask
- **Servidor Web:** Waitress (WSGI)
- **Interface:** HTML, Tailwind CSS, JavaScript e Chart.js
- **Dados e Ficheiros:** SQLite, OpenPyXL e PyPDF
